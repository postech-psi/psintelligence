# 실험 계획 B — 물리 잔차 학습 (GRU가 탄도식의 보정량만 학습)

## 배경

학습 없는 물리 기준선 `H_phys = h + ln(1 + k·v²/g)/(2k)`는 평활 상태에서 test 관성 MAE 1.29 m(bias −0.08)로,
배포 GRU(1.96 m, bias +0.27)보다 낫다. 그래도 남은 오차가 있다. 원인 후보는 다음과 같다.
- 수직 1차원 가정(발사각 70–90°)
- k 추정 잡음과 가속도 bias
- 평활 상태 지연

물리식이 큰 부분을 설명하므로, GRU에는 아포지 전체가 아니라 **잔차만** 맡기는 편이 데이터 효율과
외삽(학습 범위 밖 기체)에 유리할 것으로 본다.

## 가설

`H = H_phys + Δ`, `Δ = 20·(r − 1)` (|Δ| < 10 m, r은 기존 GRU 출력 `1 + 0.5·tanh`)로 학습하면 다음 둘보다
test 관성 MAE가 낮아진다.
- 물리 기준선 단독
- 실험 A의 최선 변형

## 변형 (GRU 32×1, 창 100, stride 10, 120 epoch, patience 12, 시드 42·43)

| 이름 | 입력 특징 (9) | 출력 |
|:--|:--|:--|
| B0 `physics` | 학습 없음 | `H_phys` (평활 h, v + 온라인 k) |
| B1 `residual` | 기압, 평활 v, 가속도, tilt, gyro, q(평활), **coast 플래그, k 추정, 물리 잔여상승 `H_phys − h`** | `H_phys + 20·(r − 1)` |

- 관성 판정 전 행(연소 구간 이력)에서는 k와 잔여상승이 정의되지 않으므로 0으로 채우고 coast 플래그를 0으로 둔다.
- 손실은 `MSE((H − H_true)/10 m)`다. 비율 손실을 쓰지 않는 것도 설계의 일부이므로 실험 A와 손실 형태가 다르다.
- 출력 범위 ±10 m는 물리 기준선 test P95(4.5 m)의 두 배 이상이다. 포화 비율을 함께 기록한다.
- 펌웨어 호환: 출력 헤드가 기존 `Kernel::ratio()`와 같은 `1 + 0.5·tanh` 형태다. 펌웨어에서는 `H = H_phys + 20·(r − 1)`만 바꾸면 된다.

## 고정 조건

실험 A와 같다. 같은 데이터, 리플레이, 분할, **같은 endpoint 집합**을 쓴다. 스케일러는 train에서만 fit하고, 선택은 validation으로 한다.

## 평가

실험 A와 같은 표(전체 / 첫 1 s / 직전 1 s / 비행별 마지막 / 남은 시간 대역)에 B0, B1, 그리고 A0·A1·A2를
나란히 놓는다.

## 판정 기준 (실행 전 고정)

- **채택**: B1의 test 관성 MAE가 **두 시드 모두** B0와 실험 A 최선 변형보다 0.1 m 이상 낮을 때.
- B1이 B0보다 나쁘면 "학습이 물리식에 오차를 더한다"고 결론을 내린다. 이 경우 GRU 없이 물리 기준선을 쓰는 쪽을 권고한다.
- bias가 ±0.3 m를 넘으면 개선 여부와 별개로 보고한다(과대추정 문제의 원래 질문).
